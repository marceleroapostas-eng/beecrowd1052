\# Beecrowd 1052 - Mês



\## Descrição



Este programa resolve o problema 1052 do Beecrowd.



\## Tecnologias utilizadas



\- Java

\- NetBeans

\- Maven



\## Entrada



A entrada contém um valor inteiro entre 1 e 12.



\## Saída



O programa apresenta o nome do mês correspondente ao número informado, em inglês e com a primeira letra maiúscula.
